# Scenario Library

## TS001 — Head-on convergence

The existing TS001 game save is the observation fixture for Prototypes 01 and 02.

Two native GIANTS AI field workers follow independent routes that ultimately converge head-on. The scenario must remain unchanged during the first evidence run so the prototype observes a naturally occurring conflict rather than one constructed around its thresholds.

Prototype 01 established early conflict detectability. Prototype 02 reuses the unchanged encounter to observe the Conflict Formation Window and determine when the projection becomes stable enough to classify as established knowledge.

See `docs/prototypes/PROTOTYPE_02_CONFLICT_CONFIDENCE.md` for the current hypothesis, evidence contract and test procedure.
