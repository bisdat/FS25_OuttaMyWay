# Scenario Library

## TS001 — Head-on convergence

The existing TS001 game save is the unchanged observation fixture for Prototypes 01, 02 and 03.

Two native GIANTS AI field workers follow independent routes that ultimately converge head-on. The scenario must remain unchanged so each prototype observes a naturally occurring conflict rather than one constructed around its thresholds.

- Prototype 01 established early conflict detectability.
- Prototype 02 distinguished transient conflict formation from established future conflict.
- Prototype 03 observes whether manoeuvre ordering creates a Candidate Option Preservation Window before both trajectories settle.

See `docs/prototypes/PROTOTYPE_03_OPTION_PRESERVATION.md` for the current hypothesis, evidence contract and test procedure.
