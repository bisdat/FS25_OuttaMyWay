# Prototype 28 — Productive Coverage Residual / Intent-Based Settlement

**Build:** v4.7.65 TEST BUILD  
**Historical authority at prototype creation:** passive evidence only over owner-declared v4.7.49. Current implementation baseline is owner-declared canonical v4.7.76; this prototype remains non-authoritative.

## Question

Can the pattern of Demonstrated Productive Coverage support worker-specific Potential Demand without predicting a GIANTS route, and can the *native intent lifecycle* identify when that residual-supported purpose has been satisfied early enough for Traffic Policeman reassessment?

## v4.7.64 finding — geometric settlement falsified

The coarse first-Productive backward corridor successfully identified Condor's split-start unfinished region and later recorded real Productive coverage entering it. In the manually perturbed run Condor productively returned to its original start region and GIANTS then entered a new turn/reposition with only 136/185 projected cells painted. The unpainted remainder was plausibly approximately the headland-width strip, but neither that width nor the 73.5% ratio has semantic authority.

Therefore **complete coarse-cell filling is not Residual Settlement**. The residual is a Potential Demand representation, not an exact agronomic-completion polygon.

## v4.7.65 probe

At the first positively Productive sample of each Job Episode, retain the existing coarse backward-corridor residual. All unrelated unpainted cells remain UNKNOWN.

Observe an ordered intent witness:

1. **Productive re-entry** — new demonstrated productive coverage appears inside the supported residual.
2. **Coherent return consumption** — later positive coverage continues while the live working segment progresses toward the originating productive region.
3. **Origin reacquisition** — the returning Productive working-footprint sweep reacquires the captured first-Productive origin band at the same grid Representation Fitness used by Demonstrated Productive Coverage.
4. **Native purpose transition** — after those witnesses, Productive Continuation changes positively to GIANTS `TURN_SEGMENT`.

Only the ordered combination records `RESIDUAL_INTENT_SETTLED`. Full geometric filling may be logged but has no settlement/retirement authority by itself.

At intent settlement, reuse the existing field-bounded Future-Space representation to shadow-check the settling worker against other active workers in the same Field World. A positive coarse intersection records only that Traffic Policeman reassessment would have been warranted. It does not authorize Regulation, Hold, Reposition, Refuge selection or Control.

## Falsification

The hypothesis weakens if natural runs do not produce the ordered witness around visually obvious split-start completion, if the origin reacquisition witness fires on unrelated productive lines, or if the resulting settlement point does not correspond to GIANTS abandoning the return-purpose that the residual represented.
