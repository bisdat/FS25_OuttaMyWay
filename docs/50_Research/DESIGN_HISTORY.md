# Design History

## Architectural Pivot

OuttaMyWay evolved from collision detection to situational understanding.

## Repository-first milestone

The project adopted a repository-first engineering methodology where knowledge is preserved in versioned documentation rather than conversational history.

## Architecture recovery milestone — v4.6.50

Temporary v4.6.44–v4.6.49 proved several useful capabilities but also demonstrated that fixture-bounded controllers had accumulated architectural responsibilities. The project paused behavioural work, audited the active path, recovered canonical Knowledge and constraints, retired five underdefined labels and established a passive shadow authority trace as the next implementation boundary.
