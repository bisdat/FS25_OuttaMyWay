# Replacement-core documentation lineage

The files in this directory form the historical replacement-core architecture
and implementation-contract lineage. They no longer define current intended
architecture. Current accepted system architecture is routed through
[`docs/architecture/README.md`](../../architecture/README.md).

Some of these documents still describe structures that remain in the inherited
live implementation. That implementation persistence does not restore the
documents' architectural authority: obsolete implementation and obsolete
documentation do not validate each other merely because they remain mutually
consistent.

This directory also contains experimental-lineage and donor/removal provenance
used to understand how the replacement-core implementation was reached and
later retired.

These files remain archived only while semantic reconciliation and
dependency/reference closure need them. Once that purpose is exhausted, their
deletion from the working tree is expected; Git history retains the permanent
record.
