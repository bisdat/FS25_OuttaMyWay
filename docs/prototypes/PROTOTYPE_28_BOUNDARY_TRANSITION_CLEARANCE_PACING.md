# Prototype 28 — Boundary Transition-Clearance Pacing

**Build:** v4.7.56 TEST BUILD  
**Historical authority at prototype creation:** owner-declared v4.7.49. Current implementation baseline is owner-declared canonical v4.7.76; this prototype remains non-authoritative.

## Question

Can the already-validated leader/follower Regulation playbook remain unobtrusive while preserving enough Action Space that, if native boundary-intent revelation matures into an opposed head-on, the already-proven Refuge/Reposition playbook can start before GIANTS native blockage?

## Evidence motivating the test

v4.7.54 successfully preserved the D-0124 Regulation lifecycle and D-0125 same-Commitment strategy succession, but its second head-on Refuge decision arrived after Condor had already become natively blocked. The current geometry-derived cap had arranged near-zero slack: Patriot reached approximately the demonstrated demand as Condor completed the demonstrated manoeuvre. That was adequate sequencing but insufficient Transition Clearance for the next playbook.

## Bounded test mechanism

The geometry-derived maximum follower speed remains the diagnostic reference. v4.7.56 applies **90%** of that value as a temporary empirical Transition-Clearance calibration factor. Example only: a 19.6 km/h derived maximum becomes a 17.6 km/h applied cap.

The 0.90 factor is not production speed policy, a new architectural threshold, a reaction-time model, or a claim about hidden GIANTS truth. It tests adequacy: whether modestly more conservative pacing leaves useful Action Space without becoming visibly excessive. Provisional Demand Seed remains inactive.

## HUD housekeeping

The obsolete OTM lifecycle and P22 diagnostic HUD surfaces are disabled. Build identity and active pacing explanation move to the existing right-hand OuttaMyWay display area. Detailed P22/OTM forensic evidence remains in the log.

## Pass evidence

A useful PASS requires more than collision avoidance:

1. follower Regulation admits once and persists without oscillation;
2. applied pacing is materially below the raw derived maximum by the configured test factor;
3. if Condor reveals opposed continuation, the head-on is recognised while both participants remain mobile;
4. the second Refuge/Reposition playbook starts with usable Action Space rather than from native blockage;
5. the second head-on resolves through the same unresolved Commitment; and
6. Patriot pacing remains operationally acceptable rather than becoming a disguised Hold.

The later diagonal cross-field continuation remains out of scope.
